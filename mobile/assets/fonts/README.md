# Tipografia do Garagem Digital

Barlow Condensed (Semibold e Bold) é usada nos títulos e números. Manrope
(fonte variável) é usada nos textos e controles. Os arquivos são incluídos
no aplicativo: não há download de fontes durante o uso.

Fontes oficiais: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
e https://github.com/google/fonts/tree/main/ofl/manrope (obtidas em 21/09/2026).
